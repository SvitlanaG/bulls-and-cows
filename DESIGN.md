# Design notes

## Структуры данных и алгоритмы

- `GameState` в `src/core.ts` — неизменяемое значение с длиной, основанием системы, секретом, статусом и `readonly` историей. `submitGuess` возвращает исходное состояние для неверной, повторной или уже завершённой попытки. Для принятой попытки он создаёт новый объект и новый массив `[...state.history, entry]`, поэтому предыдущие состояния остаются пригодны для сравнения и тестирования.
- `GuessEntry` хранит исходный ввод, количество bulls и cows. UI строит строки истории из этого массива, не меняя старые записи.
- Рекорды — массив записей в `localStorage`. Они сортируются по числу попыток, затем по времени; сохраняются первые десять. Настройки длины и основания включены в каждую запись.
- `evaluateGuess` сначала приводит символы обоих значений к нижнему регистру. `map` отмечает цифры секрета, присутствующие в попытке; `reduce` считает совпадения на тех же позициях (bulls); `filter` считает все совпавшие цифры, после чего из их числа вычитаются bulls, чтобы получить cows.
- `countPossibleSecrets` использует рекуррентное соотношение `P(length, base) = base × P(length - 1, base - 1)` с `P(0, base) = 1`. При `length > base` ответ равен нулю. Результаты промежуточных пар аргументов хранятся в `Map`, поэтому повторные обращения используют мемоизированное значение.
- `createDigitValidator(base)` — каррированная функция: один раз выбирает алфавит основания и возвращает предикат для проверки отдельного символа. `isValidGuess` применяет его через `every`, затем проверяет уникальность нормализованных цифр через `Set`.

## Сложность

Обозначения: `n` — длина секрета/попытки, `b` — основание системы.

- `generateSecret`: `O(n × b)` времени и `O(b)` памяти. На каждом шаге `splice` удаляет выбранную цифру из остаточного алфавита размером не более `b`.
- `evaluateGuess`: `O(n²)` времени и `O(n)` памяти. Для каждой цифры `map` вызывает `includes` по секрету длины `n`; дополнительные `reduce` и `filter` линейны.
- `isValidGuess`: ожидаемое `O(n)` времени и `O(n)` памяти. `every` проверяет символы, а `Set` выявляет повторения за ожидаемое постоянное время на вставку.
- `countPossibleSecrets`: `O(n)` времени и `O(n)` глубины стека для одного нового вызова. Рекурсия уменьшает оба аргумента на каждом шаге, а `Map` позволяет вернуть сохранённые значения; память кэша растёт по числу вычисленных пар аргументов.

## Принципы чистого кода

- **Одна ответственность и короткие функции:** игровые правила изолированы в `src/core.ts`; DOM, таймер и `localStorage` находятся в `src/main.ts`. Например, `evaluateGuess` только вычисляет подсказку, а `saveRecord` только сортирует и сохраняет результаты.
- **Явные зависимости:** `generateSecret` принимает источник случайности параметром, поэтому тесты передают детерминированную функцию вместо глобального `Math.random`.
- **Неизменяемые данные:** `submitGuess` создаёт новый объект состояния и новый массив истории; типы `GameState` и `GuessEntry` описывают данные как `readonly`.
- **Имена отражают назначение:** `createDigitValidator`, `isValidGuess`, `countPossibleSecrets` и `evaluateGuess` называют конкретное правило или результат, а `GuessEntry` и `GameState` задают понятные типы.
- **Избегание повторов:** `createDigitValidator` используется и в проверке всей попытки, и при фильтрации символов в поле ввода; таблица систем счисления `bases` задаёт подписи и значения для настроек и рекордов.
- **Проверки FIRST и TDD:** `src/core.test.ts` содержит быстрые самостоятельные проверки с фиксированными входами и прямыми ожиданиями. Тесты добавлялись до реализации каждой обязательной функции; красные тестовые и зелёные реализационные шаги сохранены отдельными коммитами.

## Запуск проекта

- `npm install` — установить инструменты разработки.
- `npm test` — выполнить тесты Vitest.
- `npm run lint` — проверить TypeScript и конфигурацию.
- `npm run build` — скомпилировать TypeScript в ES-модули каталога `dist`.
- `npm run dev` — собрать TypeScript и открыть страницу через Vite.

Husky запускает только `lint-staged` (ESLint и Prettier) перед коммитом и `npm test` перед отправкой коммитов.
